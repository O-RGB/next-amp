Privacy Policy

A clear description of how NextStudio handles information.

Effective date: September 12, 2026·Version 1.0

NextStudio is developed by NextFeeder Labs. This Privacy Policy explains how the NextStudio browser Extension, its optional Go engine and the public Remote page handle information.

In shortNextStudio is designed to process audio locally on your device. We do not sell personal information, use personalized advertising, or receive your ordinary audio stream for AI processing.

1. Information we handle

Audio and video. When you explicitly activate a feature, the Extension may capture audio from the selected browser tab under the browser’s permission model. Audio is processed in the browser or through the optional local Go engine. The Remote controller does not receive or relay the audio stream.

Recordings. If you use recording, the resulting audio is kept in local browser storage on the device running the Extension. You can play, download and delete recordings from the app. Recordings are not uploaded to NextFeeder Labs in normal operation.

Settings and session state. Preferences such as effects, AI mode, video settings and local session state may be stored using the browser’s local Extension storage so the app can restore your choices.

Remote connection data. Remote uses a short-lived session identifier, a host identifier and a token supplied in the Remote URL fragment. The Remote page sends validated control messages, such as volume, pitch, vocal mode and video timing. PeerJS signaling and WebRTC connection setup may expose normal connection metadata such as IP address and timing to the relevant network service. The control token should be treated as private and should not be posted publicly.

2. Third-party services

The Remote connection uses PeerJS-compatible signaling infrastructure to discover and establish the peer connection. That service may process technical connection metadata according to its own policies. Once a peer connection is established, NextStudio uses it for the data-only Remote protocol described above.

The public site does not include analytics, advertising trackers, third-party font requests or remote JavaScript. If you follow an optional support or donation link, that destination is operated by its own provider and its privacy policy applies there.

3. Retention and deletion

Local recordings and preferences remain on your device until you delete them, clear the Extension’s site data, uninstall the Extension or the browser removes the relevant storage. Remote connection state is session-based and is discarded when the Extension session ends or the connection is closed. Exact session expiry may vary by release; this page will be updated when the data flow changes.

To delete a recording, use the app’s delete action. To remove saved preferences, clear the Extension’s stored data in your browser. To end a Remote session, disconnect the Remote page and stop the Extension session.

4. Use of information

Information is used only to provide, maintain and troubleshoot the features you request, including audio effects, AI vocal processing, recording, video synchronization and Remote control. NextFeeder Labs does not sell information or use it for personalized advertising.

5. Security

The public Remote page uses a data-only protocol, validates outbound controls and does not execute content received from the Extension. The corresponding Extension-side command allowlist is part of the production integration checklist. No security design can eliminate every risk, so keep session URLs and tokens private and use HTTPS when deploying the public site.

6. Children and sensitive information

NextStudio is a general-purpose creative tool and is not directed to children. Do not place personal, confidential or sensitive information in a Remote URL, recording title or support message.

7. Changes to this policy

We may update this policy when NextStudio’s features or data flow change. The effective date and version at the top of this page will identify the current version. The policy describes the behavior intended for the current public release and will be updated before a material service change.

8. Contact

For privacy questions or requests, contact nextfeeder.ts@gmail.com.

Chrome Web Store Limited Use disclosure

NextStudio’s use and transfer of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Information received from Chrome APIs is used only to provide user-facing features requested by the user, is not sold, and is not used for creditworthiness or lending purposes.

NextStudio พัฒนาโดย NextFeeder Labs นโยบายนี้อธิบายว่า NextStudio Extension, Go engine เสริม และหน้า Remote สาธารณะจัดการข้อมูลอย่างไร

สรุปสั้น ๆNextStudio ออกแบบให้ประมวลผลเสียงในอุปกรณ์ของคุณ เราไม่ขายข้อมูลส่วนบุคคล ไม่มีโฆษณาแบบเจาะจงบุคคล และไม่รับ audio stream ปกติของคุณไปประมวลผล AI

1. ข้อมูลที่ระบบจัดการ

เสียงและวิดีโอ เมื่อคุณเปิดฟีเจอร์อย่างชัดเจน Extension อาจรับเสียงจากแท็บ browser ที่เลือกตามระบบ permission ของ browser เสียงจะถูกประมวลผลใน browser หรือ Go engine ที่ทำงานในเครื่องตามตัวเลือกของคุณ หน้า Remote ไม่รับและไม่ส่งต่อ audio stream

เสียงที่บันทึก หากใช้ฟีเจอร์บันทึก เสียงจะเก็บใน local storage ของ browser บนอุปกรณ์ที่เปิด Extension คุณเล่น ดาวน์โหลด และลบได้ เสียงจะไม่ถูกอัปโหลดไปยัง NextFeeder Labs ตามการทำงานปกติ

การตั้งค่าและ session ค่าต่าง ๆ เช่น effect, AI mode, video setting และสถานะ session อาจถูกเก็บใน local Extension storage เพื่อให้ระบบจำค่าที่คุณเลือกไว้

ข้อมูลการเชื่อมต่อ Remote Remote ใช้ session identifier, host identifier และ token ที่อยู่ใน URL fragment ของ Remote โดยส่งเฉพาะคำสั่งที่ตรวจสอบแล้ว เช่น volume, pitch, vocal mode และ video timing ระบบ signaling ที่เข้ากันได้กับ PeerJS และขั้นตอน WebRTC อาจเห็น metadata ทางเทคนิค เช่น IP address และเวลาเชื่อมต่อ ตามนโยบายของบริการนั้น ควรถือว่า token เป็นข้อมูลส่วนตัวและไม่เผยแพร่สู่สาธารณะ

2. บริการภายนอก

การเชื่อมต่อ Remote ใช้โครงสร้าง signaling ที่เข้ากันได้กับ PeerJS เพื่อค้นหาและเริ่มการเชื่อมต่อระหว่างอุปกรณ์ บริการนั้นอาจประมวลผล metadata ทางเทคนิคตามนโยบายของตนเอง หลังเชื่อมต่อแล้ว NextStudio ใช้ data-only Remote protocol ตามที่อธิบายไว้ข้างต้น

เว็บไซต์สาธารณะไม่มี analytics, ตัวติดตามโฆษณา, การเรียกฟอนต์จากภายนอก หรือ remote JavaScript หากคุณกดลิงก์สนับสนุนหรือ donate ปลายทางจะอยู่ภายใต้ผู้ให้บริการและนโยบายความเป็นส่วนตัวของผู้ให้บริการนั้น

3. ระยะเวลาเก็บและการลบ

เสียงที่บันทึกและการตั้งค่าจะอยู่ในอุปกรณ์จนกว่าคุณจะลบ ล้างข้อมูลของ Extension ถอนการติดตั้ง Extension หรือ browser ลบ storage ที่เกี่ยวข้อง สถานะ Remote เป็นแบบ session และจะถูกทิ้งเมื่อ session จบหรือปิด connection ระยะหมดอายุที่แน่นอนอาจแตกต่างตาม release และจะอัปเดตหน้านี้เมื่อ data flow เปลี่ยน

ลบเสียงที่บันทึกได้จากปุ่มลบในแอป ลบค่าที่จำไว้ได้โดยล้างข้อมูล Extension ใน browser และจบ Remote ได้โดย disconnect หน้า Remote หรือหยุด session ของ Extension

4. การใช้ข้อมูล

ข้อมูลถูกใช้เพื่อให้บริการและแก้ไขปัญหาฟีเจอร์ที่คุณเรียกใช้เท่านั้น เช่น audio effects, AI vocal, recording, video synchronization และ Remote control NextFeeder Labs ไม่ขายข้อมูลและไม่ใช้เพื่อโฆษณาแบบเจาะจงบุคคล

5. ความปลอดภัย

หน้า Remote สาธารณะใช้ data-only protocol ตรวจสอบคำสั่งขาออก และไม่ execute เนื้อหาที่ได้รับจาก Extension ส่วน allowlist ฝั่ง Extension เป็นงานในขั้นตอน production integration ไม่มีการออกแบบความปลอดภัยใดกำจัดความเสี่ยงได้ทั้งหมด จึงควรเก็บ URL และ token เป็นความลับ และใช้ HTTPS เมื่อนำเว็บขึ้นจริง

6. เด็กและข้อมูลอ่อนไหว

NextStudio เป็นเครื่องมือสร้างสรรค์ทั่วไปและไม่ได้ทำมาเพื่อเด็กโดยเฉพาะ อย่าใส่ข้อมูลส่วนตัว ข้อมูลลับ หรือข้อมูลอ่อนไหวใน Remote URL ชื่อ recording หรือข้อความติดต่อ

7. การเปลี่ยนแปลงนโยบาย

เราอาจปรับปรุงนโยบายเมื่อฟีเจอร์หรือ data flow ของ NextStudio เปลี่ยน วันที่มีผลและ version ด้านบนจะบอกฉบับปัจจุบัน นโยบายนี้อธิบาย behavior ที่ตั้งใจไว้สำหรับ public release ปัจจุบัน และจะอัปเดตก่อนมีการเปลี่ยนแปลงบริการที่มีสาระสำคัญ
