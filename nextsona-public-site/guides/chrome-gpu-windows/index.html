WINDOWS + CHROME GUIDE

How to make Chrome use the right GPU on Windows.

A practical guide for laptops and desktops with integrated and dedicated graphics — especially when Chrome-based audio tools feel slow, stutter, or stop responding.

Updated September 23, 2026·NextFeeder Labs

If NextSona shows GPU Slow, AI Vocal takes too long to start, or playback appears to sit at Buffering 0.0s, Chrome may be using the power-saving GPU — or hardware acceleration may not be available.

This guide follows four simple Windows steps. The menu names can vary slightly between Windows 10 and Windows 11.

STEP 1

1. Access Graphics Settings.

Press the Windows key and search for Graphics settings. On Windows 11, you can also open Settings → System → Display → Graphics.

STEP 2

2. Browse for Chrome.

Under the desktop or classic app option, choose Browse and locate the Chrome application file.

C:\Program Files\Google\Chrome\Application\chrome.exeC:\Program Files (x86)\Google\Chrome\Application\chrome.exe%LOCALAPPDATA%\Google\Chrome\Application\chrome.exe

If your Chrome installation is in a different folder, select the chrome.exe that belongs to the Chrome you normally open.

STEP 3

3. Open Chrome Options.

After Chrome appears in the app list, select it and click Options. If several Chrome entries appear, use the one that points to the installation you actually use.

STEP 4

4. Enable High Performance.

Select High performance, confirm the GPU name shown by Windows, and click Save. Then close every Chrome window and open Chrome again before testing NextSona.

This is an original NextSona guide based on the Windows and Chrome workflow. Menu names may vary slightly between Windows 10 and Windows 11.

คู่มือ WINDOWS + CHROME

ตั้งค่าให้ Chrome ใช้ GPU ที่เหมาะสมบน Windows

คู่มือสำหรับคอมพิวเตอร์ที่มีทั้งการ์ดจอออนบอร์ดและการ์ดจอแยก โดยเฉพาะกรณี Chrome ทำงานช้า กระตุก หรือ NextSona AI Vocal เริ่มทำงานไม่สำเร็จ

อัปเดต 23 กันยายน 2026·NextFeeder Labs

ถ้า NextSona ขึ้น GPU Slow, AI Vocal ใช้เวลานานกว่าจะเริ่ม หรือค้างที่ Buffering 0.0s สาเหตุหนึ่งอาจเป็น Chrome กำลังใช้ GPU แบบประหยัดพลังงาน หรือระบบไม่สามารถใช้ hardware acceleration ได้

คู่มือนี้เรียงตาม 4 ขั้นตอนหลักของ Windows ชื่อเมนูอาจแตกต่างเล็กน้อยระหว่าง Windows 10 และ Windows 11

ขั้นตอนที่ 1

1. เปิด Graphics Settings

กดปุ่ม Windows แล้วค้นหา Graphics settings หรือใน Windows 11 ไปที่ Settings → System → Display → Graphics

ขั้นตอนที่ 2

2. Browse หา Chrome

ในส่วน Desktop app หรือ Classic app ให้กด Browse แล้วเลือกไฟล์ของ Chrome

C:\Program Files\Google\Chrome\Application\chrome.exeC:\Program Files (x86)\Google\Chrome\Application\chrome.exe%LOCALAPPDATA%\Google\Chrome\Application\chrome.exe

ถ้า Chrome อยู่คนละโฟลเดอร์ ให้เลือกไฟล์ chrome.exe ของ Chrome ที่คุณใช้งานจริง

ขั้นตอนที่ 3

3. เปิด Chrome Options

เมื่อ Chrome ปรากฏในรายการ ให้เลือก Chrome แล้วกด Options ถ้ามีหลายรายการ ให้เลือกตัวที่ตรงกับ Chrome ที่คุณเปิดใช้งานจริง

ขั้นตอนที่ 4

4. เลือก High Performance

เลือก High performance ตรวจสอบชื่อ GPU ที่ Windows แสดง แล้วกด Save จากนั้นปิด Chrome ให้ครบทุกหน้าต่างแล้วเปิดใหม่ก่อนลองใช้ NextSona

นี่คือคู่มือฉบับเรียบเรียงใหม่ของ NextSona โดยอ้างอิงขั้นตอน Windows และ Chrome เมนูอาจแตกต่างเล็กน้อยระหว่าง Windows 10 และ Windows 11
